## 模板保持与有意差异

行尾按钮交互反馈：启用的按钮悬停时图标由 16px 平滑放大到 18px 并加深颜色，按下时缩回 16px；按钮始终为 28×28px，背景保持透明，键盘焦点环及禁用状态保留。动画时长 120ms，遵循系统减少动态效果设置。仅做源码调整、静态核对与格式化，未构建、测试或提交。

行尾按钮尺寸更新：三个透明图标按钮由 24×24px 调整为与参考稿一致的 28×28px，仍使用 16px 图标及无背景状态。按钮组与覆盖层统一扩展到 84px，和末列既有最小宽度一致；仅显示名称列时继续保留文件图标/复选框槽。仅做源码调整、静态核对与格式化，未构建、测试或提交。

底部拖拽边缘同步：底部面板改为与左右侧栏共用同一分隔线实现，保留 1px 中性细线，只在正中显示 64×4px 横向圆角短握柄；悬停、拖拽与键盘聚焦的配色及 9px 输入热区均与侧栏一致，不高亮整条边缘。底部使用上下方向键按 8px 微调，既有高度限制、尺寸保存及收起完全隐藏行为保留。仅做源码调整、静态核对与格式化，未构建、测试或启动应用。

行尾操作外观补充：三个图标按钮改为在最后一个可见数据列内靠左排列，移除覆盖层背景及按钮在悬停/按下时的背景，保留行本身的悬停/选中色、图标颜色反馈与键盘焦点环。显示操作时隐藏被覆盖的数据，离开后恢复；若仅显示名称列，保留图标/复选框槽，操作从文件名内容起点排列并隐藏文件名，避免文字叠在透明图标后方。不新增列、不改变列宽及动作对象。仅做源码调整、静态核对与格式化，未构建、测试或提交。

显示列入口位置更新：按最新要求，从普通表头末端及选中表头移除列设置按钮，统一放到表头上方既有工具栏最右侧（“更多”右侧）。图标由 `columns-3` 改为官方 Lucide `funnel`，仍保留“显示列”名称/提示、键盘打开、列显隐、列宽重置和配置记忆。入口不新增表格列、不占数据单元格，也不增加工具栏行。仅做源码与资源调整、静态核对和格式化，未构建、测试或启动应用。

最新工具栏与表格调整：类型筛选图标改为 Lucide `list-filter`，站点下拉只在“更多”中提供，“更多”始终可访问；左栏全部任务使用 `layout-list`。工具栏新增“清理已完成”，宽度不足时保留图标按钮，只移除已完成任务记录，保留文件。应用菜单增加关于、队列入口和任务全部开始/暂停；分组带展开箭头，可滚动及键盘展开，关于使用既有模态弹窗风格。全部开始跳过完成和已运行项，全部暂停同时停用夜间定时启动。

表格改为单一列模型：名称/大小/进度/速度/剩余/队列/状态/添加共八个可配置数据列，不增加操作列，也不允许横向滚动。表头右侧的“显示列”按钮可勾选数据列（名称保留），窗口较窄时暂时收起低优先级列，设置中标记“空间不足”；数据恢复空间后重新显示。列宽通过表头边界拖拽或左右方向键调整，拖拽时同步调整相邻列，总宽保持在任务区范围内。表头与内容共用列宽并预留纵向滚动条空间，显隐及宽度偏好保存到现有面板配置，重置面板尺寸不会覆盖列偏好。

按用户补充，行尾三项操作覆盖最后一个可见数据列的原值：开始/暂停、打开文件位置、打开详情采用三个 24px 图标按钮，悬停或行内聚焦时显示，离开后恢复值，不改变列宽。只有名称列时仅覆盖名称末端，保留文件图标及名称前部；完成任务不允许通过开始按钮打开或重启文件。按钮动作不触发行选择，聚焦按钮后 Enter 执行按钮本身的动作。侧栏共用新的分隔线组件，只有居中的 4×64px 圆角短线高亮，背景边缘保持 1px 中性细线，鼠标热区 9px，保留方向键微调与尺寸记忆。仅做源码、资源及静态引用核对与格式化，未构建、测试、启动应用或生成预览。

面板尺寸、应用菜单和文件图标更新（覆盖下文固定宽度及全部文件图标用 Lucide 的历史说明）：左侧栏改为横向 Split，右侧详情改为内容区横向 Split，底部详情改为纵向 Split；鼠标可拖拽分隔线，键盘方向键可微调。左侧默认 220px（180–480px），右侧默认 360px（至少 280px，并留出 320px 任务区），底部默认 260px 高（至少 140px，并留出 150px 任务区）；上限随窗口变化。三处尺寸独立保存在用户配置 `openidm/panel-layout.json`，后台合并写入，窗口关闭时完成最后一次保存；重启时读取，应用菜单可重置。底部面板宽度随任务区铺满、高度可拖拽；收起后仍完全隐藏，停靠位置继续独立记忆。

标题栏最左侧新增“应用菜单”按钮，菜单提供添加下载、批量下载、站点抓取、计划任务、详情停靠/显隐和重置尺寸。按钮由三个 Lucide `minus` SVG 组成，展开时上下线移至中心并旋转、中线淡出，180ms 内变成 X；关闭反向恢复，系统减少动态效果时直接切换。菜单复用统一弹层与键盘导航，支持 Escape 和点击外部关闭。任务区变窄时，筛选及次要操作进入“更多”，保留单行工具栏；选中表头同步收紧间距。

全局图标更新（按最新要求覆盖此前系统文件图标方案）：所有应用图标统一为固定提交的 Lucide 官方 SVG，包含主页面与旧版页面的工具栏、导航、菜单、弹窗、详情、文件类型、复选标记、部分选中横线、状态与排序箭头。统一入口为 `style.Icon`，原始资源与授权保存在 `style/lucide/`，通过内嵌资源离线使用并缓存解析结果。删除两套手绘图标及 Windows 文件图标提取、后台队列和位图缓存；无对应图标时使用语义接近的 Lucide，未知名称回退 Lucide `file`。字体箭头与旧版扩展名图标槽也替换为 Lucide。文件选择方式、任务动作及表头切换行为保持不变。仅做源码、资源与静态引用核对及格式化，未构建、测试、启动应用或生成预览。
