# 设计规则

主要模板为 `docs/design.html`，协作约束见根目录 `AGENTS.md`。保留模板紧凑的 shadcn/ui 风格，颜色按照用户要求映射为 Radix，避免将原稿的 zinc 原值与 Radix 混称。

## 字体与度量

- 字体：Geist + MiSans，正文 13px / 1.4；Regular 400，Medium 500。
- 11px：徽章、表头、辅助说明；12px：搜索、字段、状态栏；15px：弹窗标题；18px / 500：统计数值。
- 底部状态栏右侧计数和下载速度保持单行、不可压缩，下载图标与速度数值靠右完整显示；窗口缩小时夜间队列时间和临时状态提示可收缩并以省略号及提示保留完整内容。
- 标题栏 38、工具栏 46、按钮 28、表头 30、任务行 46、状态栏 28、侧栏宽 220。
- 圆角：徽章 5、控件 6、卡片/菜单 8；图标 16，描边 1.75。
- 界面操作、状态、箭头与控件标记使用 Lucide 官方 SVG，通过 `style.Icon` 及 `style.StrokeIcon` 描边令牌绘制，按语义色适配亮暗主题。旧名称只做别名映射，未知名称回退 Lucide `file`。按最新要求，表格文件图标例外使用系统文件图标，失败或不支持的平台回退 Lucide 类型图标。Lucide 原始 SVG 与授权内嵌到应用，固定上游提交，见 `style/lucide/README.md`。
- 菜单项固定垂直间距 2px，悬停不改变布局。导航区独立滚动，底部磁盘卡片保留位置。
- 表格的名称/大小/进度/速度/剩余/队列/状态/添加由 `cmd/opendl/page_columns.go` 的单一列模型定义，表头和内容共用宽度结果；间距取 `style.TaskTable`。禁止横向滚动：按可用宽度分配并缩放列宽，空间不足时依次临时收起添加、队列、剩余、速度等次要列；名称保留，显隐与宽度偏好不因临时收起而丢失。“显示列”按钮使用 Lucide `funnel`，固定在表头上方工具栏最右侧，不出现在普通/选中表头或数据列中；提供设置与重置，临时收起项显示“空间不足”。列边界拖拽及左右方向键同时调整相邻列，保持总宽适配。
- 侧栏 220px 为默认宽度；左侧宽度 180–480px，右侧详情最小 280px，任务区最小 320px，底部详情最小 140px 高；上限随窗口可用空间变化。三处面板通过 `panelSplit` / `panelSplitVertical` 共用同一鼠标及方向键分隔线实现：中性 1px 细边，悬停/拖拽/键盘聚焦只在正中显示圆角握柄，左右为 4×64px、底部为 64×4px，输入热区均为 9px。左右使用左右方向键、底部使用上下方向键，每次 8px。尺寸和列配置独立保存在 `opendl/panel-layout.json`，重置面板尺寸不清除列偏好。底部宽度铺满任务区、高度可拖拽，收起时完全隐藏。
- 工具栏根据实际任务区宽度适配；不足 800px 时类型/日期在应用菜单的筛选分组中提供，不足 560px 时继续/暂停/停止可从应用菜单的任务分组操作。工具栏移除“更多”，右侧依次放置“添加 URL”和 `funnel` 显示列按钮。不显示站点下拉；“类型”图标使用 `list-filter`，侧栏“全部任务”使用 `layout-list`。清理已完成在窄栏中使用图标按钮，其他宽度显示文字按钮；仅移除完成记录，不删除文件。
- 主窗口和设置窗口保持原有亮暗主题纯色背景，不使用壁纸色调的系统窗口材质。
- 工具栏最左侧的按钮控制主窗口左侧栏展开和收起，图标及无障碍名称随状态切换；侧栏宽度和折叠状态分别记忆，收起时内容区取得释放的空间，过渡遵循系统减少动态效果设置。
- 标题栏最左侧菜单按钮由三条 Lucide `minus` 组合，通过 180ms 平移、旋转与透明度动画变成 X；减少动态效果时直接切换。菜单复用现有弹层及键盘导航，支持 Escape 和点击外部关闭。
- 主界面只保留一个 46px 工具栏，合并全局任务操作与筛选；移除统计卡片区和独立筛选行。窄窗口的次要操作通过应用菜单提供，避免换行；选择计数与文件操作放在选中后的表头。
- 工具栏和应用菜单不再单设与“添加下载”重复的“批量下载”入口；添加下载仍可一次输入多个链接。
- 工具栏位于内容列，与任务表同宽、同 14px 水平内边距，按钮与表格列对齐；分隔线由表头顶边承担。左侧栏从标题栏下沿直通状态栏（到顶）。**差异记录**：模板的工具栏通栏、侧栏起于其下，此处按用户最新要求改为表格同宽布局。

## 唯一色彩来源

`style.NewRules(dark).Colors` 是权威语义令牌；旧 `Palette` 和主页面适配器均从中取值。禁止给新页面新增独立色板。

| --- | --- | --- |
| 内容面 | 白色 | Gray 2 `#191919` |
| 面板 | Gray 1 `#FCFCFC` | Gray 1 `#111111` |
| 主文字/主色 | Gray 12 `#202020` | Gray 12 `#EEEEEE` |
| 次要文字/计数 | Gray 11 `#646464` | Gray 11 `#B4B4B4` |
| 悬停 | Gray 3 `#F0F0F0` | Gray 3 `#222222` |

| 按下 | Gray 5 `#E0E0E0` | Gray 5 `#313131` |
| 普通边框 | Gray 4 `#E8E8E8` | Gray 6 `#3A3A3A` |

## 组件行为

- 下拉选择使用 SelectBase，页签使用 TabsBase；复选框、开关和单选使用对应基础控件。
- 操作下拉使用 PopoverBase，共用 `d1DropdownPanel`，限速和筛选下拉保持一致的弹层样式。
- 速度限制入口位于状态栏左侧（差异记录：原约定放在左下卡片，按最新要求移至状态栏）：触发器与状态栏同高，gauge 图标 + 当前值 + 小箭头，默认显示“无限制”；点击向上弹出预设档位（无限制、1/5/10/20 MB/s）与“自定义速度…”，弹层向上展开并共用下拉弹层规格，自定义走原有对话框。左下卡片仅保留磁盘信息，剪贴板监听 Switch 已按最新要求移除；删除限速 Switch 及剪贴板说明文字。磁盘容量（名称、可用空间与用量条）统一使用 muted foreground 弱化，避免信息争夺视觉注意力（差异记录：参考稿用量条为主色填充，按最新要求调整）。
- 按钮名称、菜单快捷键、选中状态与真实动作一致；无有效选择时禁用任务操作。
- 图标+文字按钮（d1Button / d1PrimaryButton）采用轻拟物风格：28px 高、RadiusLG 圆角、Medium 字重、柔和外投影，按下投影收窄形成按压反馈；主按钮深色实心 + 主色上文字（同参考图），次级按钮浅色底 + 描边保持层级。“清除筛选”仍为约定的无边框次级样式，图标按钮与分段控件不变（差异记录：“不随意使用阴影”规则按用户最新要求对这类按钮放开，其余元素仍不使用阴影）。
- 删除入口与选择计数在无选择时直接隐藏；当前行选择与复选框选择共用动作规则，取消全选后清除当前行选择。
- 有选中项时，30px 表头隐藏全部列名，原位显示“选择框 → 已选 N 项 → 分隔线 → 打开文件 / 文件夹 / 删除 → 分隔线 → 取消选择”；清空后恢复列名，任务行不发生位移。操作使用共享令牌，删除为危险色，图标按钮带名称与提示。打开文件只对单个已完成真实文件启用，文件夹只对单项启用，删除处理全部选择（含其他筛选中保留的勾选）；隐藏选择数量在计数提示中说明。主工具栏及“更多”不重复提供这些文件操作。普通行点击保持单选，Ctrl+点击和复选框保留累加多选；Shift+点击按当前可见顺序从锚点行到目标行整段选择（含两端），Ctrl+Shift 追加到既有勾选，锚点为最近一次单选/加选的行，全选后锚点为首个可见行。
- 任务行不设独立复选框列：名称列 28px 图标槽兼任复选框（悬停/勾选/聚焦时原位显示），普通点击单选，Ctrl+点击切换多选；表头全选与行图标槽对齐。Windows 文件图标由独立 COM 后台线程提取并缓存：已完成真实文件使用文件自身图标，未完成任务按扩展名获取系统关联图标。缓存键包含完成时间，避免重新下载同路径后沿用旧图标。失败时回退 Lucide 分类图标，不改变文件选择方式。
- 不增加操作列。行悬停或聚焦时，最后一个可见数据单元格内靠左以 3 个 28×28px Lucide 按钮覆盖原值，图标默认 16px，悬停变深并在 120ms 内放大至 18px，按下缩回 16px；图标盒默认间距 12px，悬停时为 10px。按钮及覆盖层均透明，不绘制默认、悬停或按下背景；键盘保留焦点环，减少动态效果时尺寸直接切换，禁用按钮不响应悬停和按下。离开后恢复数据。最后一列至少 84px，覆盖层不改变布局。只有名称列时保留图标/复选框槽，从其后的文件名起点靠左显示操作，并隐藏文件名避免重叠。完成任务的开始操作禁用；按钮点击不触发行选择，键盘 Enter 在按钮内执行本按钮动作。
- 应用菜单包含“关于”“队列”和“任务”。带二级菜单的分组在行右侧弹出二级菜单，不在行下方展开：悬停、点击或右方向键展开，左方向键或 Escape 收起，指针移开行和弹层后带短宽限期自动收起，二级菜单复用下拉弹层的配色、边框、圆角与行规格。队列提供主/夜间队列、计划入口及全部队列开始/暂停；任务提供全部开始/暂停，两组批量动作共用任务规则：只开始待开始、暂停及失败项，完成项和正在运行项不重启；全部暂停同时停用夜间计划，全部开始重新启用。关于弹窗提供应用名称、版本及简介。
- 任务表名称下方不显示下载地址或来源；不再提供开发调试样例数据。
- 添加下载对话框“保存到”行右侧提供“选择文件夹”按钮（系统目录选择器，默认定位当前输入）与“最近目录”按钮（弹层列出当前输入、默认目录与最近六个使用过的保存目录，仅提示不自动改写）；周期同步与每个任务的连接数同列时以 12px 间距分开，媒体下载模式下周期同步隐藏。
- 表头拖拽和“显示列”菜单右侧拖拽手柄共用列顺序；松开后表头与数据行同时更新，显示插入位置，列宽和显隐与列身份绑定。列顺序持久化，隐藏或空间不足的列保留原位置；名称列固定第一列且不可隐藏，其余列不能移动到名称列之前。支持键盘调整与重置。
- DialogBase 负责模态焦点、Tab 约束和 Escape；任务快捷键仅属于任务表作用域。
- 独立设置窗口通过应用菜单或标题栏设置按钮直接打开，复用已打开窗口；左侧搜索跨分类匹配，右侧提供真实生效的外观、下载、速度、计划与界面设置。目录、连接数、剪贴板、限速和夜间计划保存在用户配置中；夜间队列默认关闭，首次启动处于停用状态，用户修改后下次启动保持；主题及详情位置继续沿用各自的既有配置；文本输入需显式保存并显示错误，修改默认值时保留已打开的添加下载草稿。
- 验证失败保留输入，字段附近显示具体错误。计划任务编辑草稿只在保存时生效。
- 设置页面只显示设置名称和必要控件，不在选项下方显示说明文字或操作成功提示；输入与保存失败时保留具体错误提示。
- 详情支持底部/右侧停靠并共用状态和内容，页签为概览、分段、请求头、日志（差异记录：原五页签按参考稿改为四页签，信息与速度并入概览）。概览排布：文件标识（主题色浅底图标 + 文件名 + 来源主机）、大号进度百分比与主题色状态点、已下/总量和“速度，剩余”行、连接级进度胶囊（按连接数量划分文件区间，各格显示区间完成度；无分段数据时退化为整条；胶囊下方不显示说明文字）、速度曲线（主题色描边与浅填充，最近 60 秒 + 峰值）、任务信息（地址、保存到、协议、断点续传、校验、添加时间；来源页移入请求头页）。右侧停靠纵向排布并以细分隔线分区，底部停靠保持三栏。分段页保留分块位图与连接列表。面板底部固定操作栏：主操作（继续/暂停/打开文件随状态切换）、打开文件夹、更多操作（复用行右键菜单，锚定按钮向上弹出；“属性”仅保留在表格行右键菜单，用于恢复收起的详情面板，面板内“更多”不显示该无效入口）。收起后完全隐藏；暂时移除工具栏右侧栏按钮，通过任务属性或 Alt+Enter 恢复原位置（差异记录：按最新要求，应用菜单不再提供展开/隐藏入口，位置与重置集中在“面板”二级菜单）。详情面板内的位置切换与收起合并为一个分段控件：两段均为图标（panel-right / panel-bottom），当前停靠段为选中态，点击收起面板（取代原关闭按钮）；另一段点击切换到对应停靠位置，名称与提示随状态切换。停靠位置保存在用户配置中。长值可选择/复制，并有完整值提示。参考稿中的蓝色一律改为主题色；协议行只显示引擎已知协议，不虚构 HTTP/2 等未提供明细。
- 模板演示数值不得混入真实业务。未提供的引擎明细明确说明；只展示已知配置与探测结果。
