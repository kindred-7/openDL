# Downloader 原生浅色方案

当前页面：design-3.html。独立 HTML，使用系统字体和内嵌图标，无外部字体、图标 CDN 或构建依赖。

## 当前方向

依据用户选定的“浅色、克制、有原生质感，像 macOS 原生应用”重新安排界面结构。

- 统一顶部工具栏：当前分类、任务数量、搜索与添加入口集中显示。
- 浅灰侧栏与白色文件列表形成轻微层次；细分隔线、轻量按钮和分段控件保持一致。
- 首页不再展示大数字统计面板。传输速度、队列状态保留在底部状态栏。
- 宽窗口下，任务概览、速度曲线和信息放在底部详情区；支持收起。小于 1280px 时详情默认收起，按需打开侧边抽屉。
- 常规任务行高 55px，文件名与来源分级显示；紧凑视图行高 43px。
- 原稿及两次修订备份均保留，未修改 Go 应用和下载引擎。

## 本轮验证

- 1440 × 900：页面无横向溢出，底部详情区 232px，概览内容无垂直溢出。
- 390 × 844：页面与列表无横向溢出；详情抽屉宽 340px，可正常打开与关闭。
- 搜索 lecture 显示 1 / 8 项；清空搜索恢复列表。
- 概览、分段连接与日志可切换，添加下载弹窗可打开。
- 浏览器已测试流程没有错误或警告；JavaScript 语法和静态元素标识检查通过。
- 之前已经验证的添加、校验、去重、多选、批量暂停与继续、移除与撤销、队列与限速逻辑继续沿用。

## 范围

页面为交互设计原型，未连接真实下载引擎。任务、速度、分段与图表使用示例数据；新增链接不请求真实文件，计划不会在后台运行。任务数据在刷新后复位。本轮以浅色方向为验收范围，未进行完整屏幕阅读器或 WCAG 合规测试。
