# 设计稿还原核对

依据 `docs/design.html`，实现为 MyGo 原生 UI；业务数据来自下载引擎，不写入稿件示例数据。

最新优化见 `ui-optimization.md`，颜色规范见 `design-rules.md`。下表保留原始还原规格；控件行为、导航间距及详情折叠以最新优化说明为准。

设置窗口按用户的极简设置要求重新组织，不以模板中示例分组为准：外观与面板归入界面，剪贴板监听、速度和流量归入下载；分类规则、队列管理、站点登录、扫描、集成认证和站点规则等低频配置默认折叠，搜索时展开。常用配置采用有效输入即时生效的交互。

设置卡片按用户提供的参考图调整为左侧名称与说明、右侧控件，相关设置合并并以分隔线区分；复杂配置保留展开区域。参考图仅用于布局，设置内容和主题令牌沿用 OpenDL。

主窗口首次启动默认 1200×720 DIP，最小尺寸调整为 680×640 DIP（差异记录：原为 1180×640，按用户要求把最小宽度收到 680，保证 1366 及以上屏幕都能把窗口缩到半屏）；窗口可调整，已有用户保存的窗口状态优先恢复。此尺寸结合当前侧栏、任务表和底部详情布局确定，参照 [Windows 窗口管理指南](https://learn.microsoft.com/en-us/windows/win32/uxguide/win-window-mgt) 按内容选择可调整的初始窗口，并非平台规定的唯一标准尺寸。

| 区域 | 实现规格 |
| --- | --- |
| 标题栏 | 38 高；最左侧应用菜单按钮以 180ms 动画由三条线变为 X；360×26 搜索框、16 图标、12 文字、11 快捷键；保留系统窗口按钮 |
| 工具栏 | 唯一的 46 高工具栏；类型图标 `list-filter`，无站点下拉；增加清理已完成（保留文件），窄栏变图标按钮；选择计数与文件操作集中到选中表头 |
| 侧栏 | 默认 220 宽，可拖拽分隔线调整；视图、队列、分类分组；底部卡片仅含磁盘信息，限速入口位于状态栏左侧，剪贴板监听开关已从侧栏移除；无额外分隔线或说明 |
| 统计卡 | 按用户要求移除；底部状态栏保留速度与队列状态 |
| 筛选栏 | 已合入唯一工具栏，不再单独占用一行 |
| 任务表 | 表头 30、行 46；8 个可配置数据列，禁止横向滚动，共享自适应宽度；表头上方工具栏最右侧的 `funnel` 按钮选列，不占表格位置；边界拖拽调宽，偏好持久化；行悬停时 3 个 28px 操作按钮覆盖最后数据列，不增设操作列；图标槽复选框及既有选择方式保留 |
| 状态 | 11 字号描边徽章；4 高进度条；完成绿色、失败红色、暂停灰色 |
| 详情面板 | 底部/右侧停靠切换，共用任务与概览/分段/请求头/日志四个页签；概览含文件标识、进度、分段胶囊、速度曲线、任务信息与底部操作栏；右侧宽度、底部高度可拖拽调整并独立记忆；收起后完全隐藏；通过任务属性或 Alt+Enter 恢复记住的位置，暂时移除工具栏右侧栏按钮 |
| 菜单 | 应用菜单包含关于、队列及任务操作，窄任务区保留筛选入口；限速/筛选复用统一弹层样式 |
| 图标 | 操作与控件标记使用 Lucide 官方 SVG，共享 `style.Icon`，24 单位画布、1.75 描边、Radix 语义色；表格文件图标使用 Windows 系统图标，后台提取及缓存，失败回退 Lucide 类型图标 |
| 对话框 | 复用主题、按钮、字号与图标；15/500 标题 |
| 设置窗口 | 独立可拖动的原生窗口，顶部标题栏、左侧搜索及分类、右侧可滚动设置卡片；复用亮暗主题、Lucide 图标与控件样式 |
| 状态栏 | 28 高、左右 14、间距 18、12 字号 |

原生窗口铺满客户区，不绘制 HTML 展示容器的 20px 外边距和模拟窗口边框。任务表只允许纵向滚动；列按可用宽度分配，必要时临时收起次要列，表头与行保持对齐。左右侧栏和底部面板拖拽时均只高亮中间短握柄（左右竖向、底部横向），详情区域维持既有停靠布局。

历史验证预览由 `TestMainPageRenderPreview` 生成，覆盖亮色、深色、1180×640 最小窗口、菜单、添加下载和计划任务。测试注册与应用相同的内嵌字体。

后续源码已优化，历史预览不代表当前版本；本次未自动构建、测试或生成新图。
