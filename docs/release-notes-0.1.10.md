本次更新改进桌面任务管理和浏览器扩展的下载体验。

- 新增任务拖拽排序，支持手动排序、边缘滚动及点击名称表头恢复名称排序。
- 新增同时下载任务数设置，可即时调整所有队列共用的并发上限。
- 优化主题切换、状态栏下载速度和磁盘使用情况的动画。
- 优化浏览器扩展界面，新增嗅探资源搜索，调整操作按钮和设置页布局。
- 桌面端不可用时，将下载交还浏览器；改进浏览器登录状态传递及 GitHub Actions 受限下载的处理。
- 修复扩展更新或重载后，已有网页中扩展上下文失效导致的报错。
- 改进 GitCode 发布失败恢复及 GitHub 发布附件名称兼容性。

浏览器扩展源码版本更新至 0.1.11。Firefox 扩展需要提交 Mozilla 重新签名后，替换安装包中的签名文件；现有签名包不会自动包含本次扩展修改。
