# OpenDL 浏览器扩展手动验收

本清单供手动验收使用。请使用包含本次改动的桌面应用和原生主机，并在浏览器扩展管理页重新加载对应的扩展。Firefox 使用安装说明中准备的独立扩展副本。首次加载或更新时，如浏览器要求确认新增权限，请按实际需要处理。

仓库中的 `build/` 和 `output/` 可能包含此前生成的旧副本，并不会随 `extension/` 源码修改自动更新。手动验收时请确认浏览器实际加载的是更新后的扩展目录；若使用安装包或压缩包，请先由用户自行重新生成。新增的 `icons/` 文件、两个语言目录和浏览器对应的 manifest 都需要包含在扩展中。

## 界面和资源

1. 打开扩展，分别在桌面端连接、未连接时查看页脚中间的连接状态，确认图标与文字显示为已连接或未连接；切换亮暗主题，检查状态图标和文字是否清晰。
2. 查看底部设置图标，进入设置并返回资源页；确认刷新按钮位于资源数量旁，资源为空时也能刷新。
3. 在有多个资源的页面打开扩展，悬停资源行，确认下载和复制图标显示、无常驻边框；移开后收起。用键盘 Tab 聚焦操作时图标应可见，并可操作。
4. 复制资源链接并粘贴核对；发送资源后应提示请求已发送至桌面端，仍需在桌面端确认添加。检查单项失败时的错误提示，以及批量操作结果。
5. 在资源页打开期间导航或重新加载页面，按提示重新扫描；确认旧页面的选择和发送状态不会误用于新页面。

## 任务页

1. 从资源列表发送一个下载，在桌面端确认添加；扩展任务页应出现对应任务及状态。下载过程中观察进度和速度，完成后观察状态变化。
2. 完成后分别点击打开文件、打开所在位置；文件不存在或桌面端断开时应有提示，重新连接后应恢复可用。
3. 将任务暂停、继续或删除，观察扩展中的状态与桌面端一致。较多任务时，使用“加载更多任务”查看较早记录；加载过程中删除任务，再观察列表是否恢复。
4. 在桌面端重启后重新打开扩展，检查新创建的浏览器任务仍显示。旧版任务可能没有浏览器来源标记。
5. 使用旧版桌面端或原生主机时，确认扩展能提示需要更新，而不是把旧版识别为完整支持任务页。

## 浏览器页面入口

1. 在普通下载链接、视频和音频上使用浏览器右键菜单，选择“使用 OpenDL 下载”，确认桌面端收到添加请求；桌面端未连接时应看到失败提示。
2. 鼠标移到音视频资源链接上，确认链接附近显示下载图标；点击后应在桌面端收到添加请求。检查不同页面位置、窗口边缘和页面滚动时按钮是否遮挡或残留。
3. 在扩展设置中关闭悬浮按钮，回到页面确认不再出现；重新启用后确认恢复。可在支持的站点检查无扩展名、但已识别为音视频的链接。
4. 对同源登录资源检查登录状态是否按设置使用；对跨源资源确认不会错误传递来源页 Cookie。移除 Cookie 权限或断开桌面端时，检查提示是否可理解。

如发现问题，请记录浏览器及版本、桌面端版本、操作步骤、资源类型、预期和实际结果；涉及登录信息或带签名的链接时，不要公开敏感内容。
