OpenDL 浏览器扩展安装说明

扩展尚未上架时，请按以下步骤手动安装。安装后可从 OpenDL 的应用菜单再次打开本说明。
如默认浏览器不是 Chrome、Edge 或 Firefox，请查看该浏览器的扩展安装规则。

Chrome / Microsoft Edge
1. 先启动 OpenDL 桌面应用，让其注册浏览器通信主机。
2. 在浏览器地址栏打开 chrome://extensions 或 edge://extensions。
3. 开启开发者模式，选择“加载已解压的扩展程序”。
4. 选择包含 manifest.json 的 extension 文件夹，也就是本说明所在的文件夹。
5. 打开普通网页，点击扩展图标；确认弹窗页脚中间的连接状态显示已连接。

请保留这个文件夹。卸载 OpenDL 或移动安装目录后，浏览器可能无法加载扩展；
重新安装到其他位置后，需要在浏览器中重新选择扩展文件夹。
应用更新后，如果浏览器仍使用旧扩展，可在扩展管理页手动重新加载。

右键链接或音视频可选择“使用 OpenDL 下载”。在页面上悬停音视频资源链接时也会出现下载按钮，可在扩展设置中关闭。任务页显示通过浏览器创建的桌面任务，可按需加载更早的任务；提示发送后需在桌面端确认添加，才会出现在任务列表。旧版创建的任务可能没有来源标记。

扩展默认使用浏览器登录状态；请先在浏览器登录站点，并确保扩展拥有 Cookie 权限。可在扩展弹窗的设置中关闭此功能。
该设置适用于从扩展资源列表发送的同源资源，不适用于浏览器下载接管。
登录状态不能替代隧道、代理或 DNS 配置；如果桌面应用无法解析或连接站点，请先配置网络。

Firefox
本文件夹的 manifest.json 是 Chrome / Edge 版本，请勿直接改写安装目录中的文件。
Firefox 需要单独准备扩展副本，将 manifest-firefox.json 替换副本中的 manifest.json，
并按 Mozilla 的自行分发流程签名后安装。未经签名的扩展不能作为普通 Firefox 的长期安装方案。
